使用帮助
1. 怎么在线下单？
首页点「纸箱报价/下单」→ 选箱型、输入尺寸、选材质和数量 → 价格实时显示 → 确认提交。也可从「常用规格」一键开始。
2. 价格是怎么算的？
按纸箱展开面积 × 纸板单价自动计算，数量越多折扣越大（选择数量时会显示各档位单价对比）。
3. 多久能交货？
标准交期 5-7 个工作日；急单可选加急 3 天（加收 15% 加急费），下单时勾选。
4. 怎么开发票？
在「我的 - 开票信息」里填好企业开票资料，订单完成后按资料开具。
5. 异型箱 / 特殊要求怎么办？
走「人工报价」入口：提交需求（尺寸、数量、用途描述）后，销售 1 小时内电话联系报价。
6. 下单后能改规格吗？
未进入生产前，联系客服修改；已排产的订单请联系客服协商处理。
