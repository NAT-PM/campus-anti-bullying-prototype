# 可点击原型 · 使用说明

> 两个原型（Web 端 + 小程序端），单文件、零依赖、离线可用。
> 版本：v1.0（高保真 · 清新绿）· 2026-08-13

## 📱 两个原型

| 原型 | 文件 | 打开方式 |
|---|---|---|
| **Web 管理端** | `prototype.html` | 双击浏览器打开（桌面端） |
| **小程序端** | `prototype_miniapp.html` | 双击浏览器打开（手机壳仿真，手机浏览器打开体验最佳） |

## Web 端演示流程（建议走查顺序）

1. **登录页**：选择角色（默认安保值班组）→ 任意账号密码 → 登录
2. **工作台**：查看待办工单 → 点击进入工单详情
3. **工单详情（核心）**：
   - 状态步骤条（未处置→处置中→审批中→已归档；审批中=班主任确认+德育处审核两环节，可配置跳过）
   - 轨迹回放（播放示意动画）+ 参数快照（人数/时长/置信度）
   - 按状态+角色渲染操作：接单 → 处置结果（可标记误报）→ 确认 → 审核 → 归档
4. **📌 逻辑标注（评审模式）**：顶栏「标注」按钮开关 ——
   - 右侧黄色便签面板：12 个页面 57 条逻辑说明（操作/跳转/字段/规则 分类标签，序号换行）
   - 关键元素 ⓘ 悬停提示（60 处）：状态机、限时处置、置信度判断规则等
   - 面板底部「导出清单」→ Markdown 文档（可直接给开发）
5. **切换角色体验权限差异**（顶栏角色下拉）：安保/班主任/德育处/访客/超管
6. **系统设置**（超管，8 个 Tab）：推送配置 / 告警规则（含置信度下限）/ 消息模板 / 数据安全 / 学校信息 / 点位字典 / 取证保留期 / 审批流开关
7. **权限管理**：角色管理（新建角色/菜单按钮权限）+ 账号管理（新建/编辑/启禁用，决定数据范围）
8. **审计日志**（超管）：登录/导出/审批/换班等操作实时留痕，不可篡改
9. **数据看板**：统计卡 + 类型分布环形图 + 近7日趋势（科技风渐变曲线）+ TOP 点位 + 时段分布

## 小程序端演示流程

1. **首页工作台**：渐变横幅（问候+统计）+ 待办事项 + 快捷入口
2. **我的工单**：4 状态筛选（未处置/处置中/审批中/已归档）
3. **告警详情**：级别渐变头图 + 参数卡 + 轨迹回放 + 底部固定操作区（接单/处置/审批按角色）
4. **巡更打卡**：进度环 + GPS 打卡（防代打）
5. **消息中心**：全量留痕，点击跳转详情
6. **我的**：账号信息 + 通知开关
7. 顶部工具栏：**演示角色切换** + **📌 标注**（浏览器右侧滑出逻辑标注面板）
8. 交互：下拉刷新、底部 TabBar（详情页自动隐藏）、页面切换动画

## 演示数据说明

所有告警、图表、设备数据均为**演示数据**（页面带"演示数据"标签），仅用于走查流程和评审。

## 状态持久化

演示操作（接单/处置/审批/配置）保存在浏览器 localStorage，刷新不丢；重置：执行 `localStorage.clear()`。

## 已验证（2026-08-13，Edge 实测）

- ✅ Web：工单 4 状态闭环、8 个设置 Tab、权限管理、审计日志、标注面板 57 条、ⓘ 提示 60 处
- ✅ 小程序：7 页面、TabBar 导航、接单→处置→审批闭环、巡更打卡、消息跳转、统一线性图标
