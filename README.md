# 可点击原型 · 使用说明

> 文件：`prototype.html`（单文件，零依赖，双击即可在浏览器打开）
> 版本：v0.1（低保真）· 2026-08-12

## 怎么打开

直接双击 `prototype.html`（用 Edge / Chrome / 任意浏览器），无需安装任何东西，**离线可用**。

## 演示流程（建议走查顺序）

1. **登录页**：选择角色（默认安保值班组）→ 任意账号密码 → 登录
2. **工作台**：查看待办工单 → 点击进入工单详情
3. **工单详情（核心）**：
   - 状态步骤条（待接单→处置中→[班主任确认*]→德育处审核→已归档）
   - 轨迹回放（点"播放"看示意动画）
   - 按状态+角色渲染的操作按钮：接单 → 填写处置结果（可标记误报）→ 确认 → 审核 → 归档
4. **切换角色体验权限差异**（顶栏角色下拉）：
   - 安保：接单/处置/巡更
   - 班主任：菜单只剩 3 项，工单只读 + 确认/驳回
   - 德育处：审核/驳回
   - 访客：只有看板+地图，只读
   - 超管：全部 + 系统管理
5. **系统设置**（超管）：
   - **推送配置**：级别 × 渠道矩阵，勾选后点「保存推送设置」
   - **告警规则**：各级别触发事件类型、判定参数（滞留阈值/聚集人数/置信度）、**限时处置分钟数**、去重窗口 —— 可修改保存，**工单页"限时 X 分钟内接单"会联动显示**
   - **取证保留期**、**审批流开关**（班主任确认跳过）
6. **角色管理**：新建角色（如"宿管组"）→ 勾选菜单/按钮权限 → 「保存权限」；内置超管锁定
7. **账号管理**：新建/编辑账号（账号/姓名/角色/手机/负责区域班级）、启禁用、重复账号校验
8. **数据看板**：统计卡 + 环形图/折线图/TOP 条形/时段分布（演示数据）

## 演示数据说明

所有告警、图表、设备数据均为**演示数据**（页面中有"演示数据"标签），仅用于走查流程和评审。

## 状态持久化

演示过程中的操作（接单、处置、审批、配置）保存在浏览器 localStorage 中，刷新不丢；需要重置时清浏览器该站点数据，或重新打开前执行 `localStorage.clear()`。
